              What this demo is

              • Agent actions are scripted, not a live model.
              • Permissions are enforced in code, then gated by your trust tier.
              • Invariants and scoring weights are frozen before a task runs.
              • Every event is hash-chained. Disputes append; nothing is edited.
              • A real deployment would need a sandboxed agent adapter.

              Earnest scores one task at a time and tracks trust per project. It does not certify that an AI model is safe in general.
